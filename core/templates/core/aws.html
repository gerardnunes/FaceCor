Como obter as chaves

  1. No console da AWS, abra IAM → Usuários → Criar usuário (sem acesso ao console).
  2. Anexe uma política restrita ao bucket (abaixo) e crie uma chave de acesso.
  3. Cole a Access Key e a Secret Key aqui e clique em Testar conexão.

As chaves ficam criptografadas no banco do sistema e nunca são exibidas de novo.

{"Version":"2012-10-17","Statement":[
 {"Effect":"Allow","Action":["s3:ListBucket"],
  "Resource":"arn:aws:s3:::SEU-BUCKET"},

  "Resource":"arn:aws:s3:::SEU-BUCKET/*"}]}

Para o sistema criar o bucket sozinho, acrescente s3:CreateBucket e s3:PutBucketPublicAccessBlock em arn:aws:s3:::SEU-BUCKET.
